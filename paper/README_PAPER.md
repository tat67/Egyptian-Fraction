# Paper: integral reciprocal sums of distinct squarefree semiprimes

This directory contains the manuscript *"Integral sums of reciprocals of distinct squarefree semiprimes: forty-seven terms are necessary, and the extremal representations of 1"*. It also contains the scripts and logs of the verification work done for it.

The paper presents the results of this repository:

* **Theorem A** ([`../README.md`](../README.md)): a nonempty set of distinct squarefree semiprimes with an integral reciprocal sum has at least 47 elements, and 47 is attained. This is the main result.
* **Theorem B** ([`../README47.md`](../README47.md)): there are exactly 23 sets of 47 squarefree semiprimes whose reciprocal sum is 1.
* **Theorem C** ([`../README48.md`](../README48.md)): with the same method, there are exactly 620 sets of 48 squarefree semiprimes whose reciprocal sum is 1. They are listed in [`../solutions48.txt`](../solutions48.txt).

The computation uses the new core search of `semiprime48.cpp`, with the loss bound (P4), for all three budgets. The earlier programs `semiprime_reciprocals.cpp` and `semiprime47.cpp` gave identical results for Theorems A and B.

All three theorems are **computer-assisted**.

* **Step 1 (the core search)** is written as a Lean function, and Lean proves that it is exhaustive (`core_mem_search`).
* **Step 2 (the completions)** is not verified in Lean. The Lean formalization proves Theorems A and B *conditionally* on the explicit hypotheses `Search46'` and `Search47'`, which state the outcome of Step 2 for the cores output by the verified search.
* For Theorem C, Step 2 is not stated in Lean at all.

See [`AUDIT_REPORT.md`](AUDIT_REPORT.md) for the precise status of every ingredient.

The previous version of the paper, based on the earlier programs and without the verified search, is preserved as `paper_oldmethod.pdf`.

## Building the PDF

The manuscript needs TeX Live 2023 or later (pdfLaTeX, BibTeX, latexmk). It uses the packages amsmath/amsthm, mathtools, enumitem, booktabs, tabularx, algorithm/algpseudocode, TikZ, natbib, hyperref, cleveref, microtype and lmodern.

```
cd paper
latexmk -pdf main.tex        # runs pdflatex and bibtex as often as needed
```

The final build has no errors, no undefined references or citations, and no overfull or underfull boxes. The only BibTeX warning is the intentionally empty title of `Johnson1978` (the title could not be verified and is not invented). `latexmk` produces `main.pdf`; the committed copy is `paper.pdf`.

## Re-running the verification

```
cd paper/verification
python3 verify_paper_facts.py                     # ~5 s; exact checks and table generation
gunzip -c ../../cores47.txt.gz > /tmp/cores47.txt
python3 analyze47.py /tmp/cores47.txt 47 11       # ~30 s; Step-2 recount for budget 47
bash step1_bruteforce/run_bruteforce.sh           # ~2 min; Step-1 brute-force validation
python3 make_tables.py                             # regenerate the log-derived tables
python3 verify48_facts.py ../../solutions48.txt   # < 1 s; the 620 sets of Theorem C
```

The runs of `semiprime48.cpp` behind Table 3 take 2 s, 65 s and 30 min on 4 cores (`../README48.md`, section "Running"). The comparison of the compiled Lean search with the C++ search is in `../validation48/lean_vs_cpp.sh`; see `../validation48/lean_runner/README.md`.

The budget-46 re-execution takes about 20–25 minutes on 4 cores, and the budget-47 re-execution about 5.4 hours. The reproduction commands are listed in `verification/rerun/README.md` and `verification/rerun47/README.md`.
